Upgrade dynamic location + nearby intelligence

- Added shared resolve_location() helper and updated /api/plan, /api/future,
  /api/nearby, and /api/ai-search to accept optional coordinates with a safe
  default fallback location when lat/lon are missing.
- Reworked nearby location discovery to be fully dynamic: generate candidate
  points around the user, evaluate each with weather/astronomy/light pollution,
  score using the scoring engine, and return top-ranked locations.
- Updated nearby response shape to expose best_locations while retaining
  recommended_locations for compatibility.
